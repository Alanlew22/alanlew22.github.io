Braced Grid — Rigidity Simulator

Instructions:
  • Move mode: drag a vertex; system keeps edge lengths constant (iterative projection).
  • Add move: click two vertices inside the same small square to add an edge (diagonal allowed).
  • Remove mode: click near an edge to remove it (initial grid edges can be removed, but pinned edge cannot).
  • Reset: restore original geometry and initial edges.
  • Reset positions: restore original geometry only, keep current edges.
Top-left vertical edge is pinned (both vertices fixed) to eliminate trivial motions.
