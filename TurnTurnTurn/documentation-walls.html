Turn turn turn! documentation

This documents Turn turn turn!, the separate browser translation of the supplied new version Python game. Play it at turnturnturn.html. The earlier no-walls game and its documentation remain unchanged; its movement has also been updated to animate as described below.

Game rules

The game has four coloured arrow pieces, a 4 × 4 grid, one matching goal square per piece, and the original coloured image controls. Unlike the older edition, every generated game has a random set of four distinct goal locations, rather than goals fixed on the diagonal.

  • Tap/click a piece to move it one cell in the direction shown.
  • Moves off the board, into a piece, or into a rock are illegal.
  • After a legal move, all other pieces orthogonally next to the destination rotate 90° counter-clockwise. Rocks never rotate or move.
  • You win when each piece reaches its own matching colour goal. Direction is irrelevant to victory; the win message appears above the board.
  • Use the icon buttons for Undo, Reset, Save, Load, and the five difficulty levels. Press S to toggle the solution sequence, displayed as colour-coded stars below the play instructions. Press H to open/close the game-rule help dialog.
  • The compact S and H buttons at the bottom-right of the canvas provide the same touch-friendly controls on mobile devices. The Load Puzzle artwork is a native file-input target so it also works on mobile.

Each legal movement is animated in the source order: the selected piece slides to its destination over 320 ms; then the adjacent pieces rotate over 260 ms. Input is locked during this animation, as it is in the original Tkinter application.

Walls: each newly generated puzzle chooses 0–3 non-overlapping rocks. The supplied rock_sprite.png is drawn on every rock. Rocks are fixed walls; despite placeholder movement methods in the Python source, there is no implemented rock-motion rule to reproduce.

Difficulty and generation parity

Easy requires 9–12 solution moves; Medium 13–15; Hard 16–19; Harder 20–24. Insane tests 5,000 random puzzles and chooses the longest. A generator walk is limited to 100 moves, as in puzzle_with_extras.py. The startup game seeks 11–13 moves in at most 10,000 attempts; normal difficulty buttons seek for at most 50,000. Every trial chooses a fresh rock count from 0–3, matching the Python UI.

The generator deliberately retains the source’s inverse internal direction convention. It creates a random solved arrangement, performs random reverse moves while rotating nearby pieces before each reverse move, then reverses the recorded move list. MakerPiece.guiDirection() converts the internal direction into the direction shown and used by the playable game.

Save format and files

Browser saves are JSON stored with a .puzzle suffix. They contain n, target, original board, solution, and rocks. As in the Python program, saving records the initial board rather than an in-progress position. It cannot read Python pickle saves: browser deserialization of pickle data would be unsafe.
